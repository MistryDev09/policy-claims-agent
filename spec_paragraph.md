This project is an AI agent that answers natural-language questions about insurance policies and performs two real calculations: a premium estimate and a claim eligibility check. It uses Amazon Bedrock Knowledge Bases for document lookup and two AWS Lambda tools for the deterministic logic, orchestrated through a Bedrock tool-use loop and deployed via AWS AgentCore. All data is synthetic. The project does not handle real customer data, authentication, or production-scale traffic, it is a scoped portfolio piece demonstrating agentic AI on AWS, not a production underwriting system. It's done when the agent correctly routes questions to the right tool(s), passes a documented eval set, and is deployed and demoable on AWS.
